Much Ho text was typed in older Warang Citi fonts, such as Boyo Gagrai and [Ghanshyam Bodra](https://rtd.theofdn.org/typefaces/ghanshyambodra11/). These fonts store each Warang Citi letter as a Latin letter. In Boyo Gagrai, type "a" and the font draws 𑣁. Open the text on a phone or computer without the same font, and only the Latin letters show. This converter changes the text into Unicode. Unicode works on every phone and computer.

[[embed:0]]

## How to use it

1. Choose the font your text was typed in.
2. Copy the text from your file and paste it in the first box. The Unicode text shows in the second box.
3. Read through the Unicode text and correct any small errors.
4. Select "Copy the Unicode text" and paste it where you need it.

To read the Unicode text, you need a Warang Citi Unicode font such as [Noto Sans Warang Citi](https://fonts.google.com/noto/specimen/Noto+Sans+Warang+Citi).

More fonts, keyboards and guides are on the [Ho language resources](/resources/hoc/) page.
