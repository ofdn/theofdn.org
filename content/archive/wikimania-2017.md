Subhashish Panigrahi presented “[8 FLOSS tools and 4 hardware for audio, video and image editing for Commons](https://wikimania2017.wikimedia.org/wiki/Submissions/8_FLOSS_tools_and_4_hardware_for_audio,_video_and_image_editing_for_Commons)” at Wikimania 2017, Montreal, Canada recently.

[[embed:0]]

The talk touch-bases some of the very user-friendly Open Source tools for image, audio and video editing that can be valuable for Wikimedians. Some of these tools include Audacity for audio editing, Blender for animation, and InkScape for vector image editing. More details for downloading the tools are given in the tools for the right operating system are given in the presentation above.
